# Specification Synchronization Skill (`saw-update-spec`)

Continuously aligns the codebase implementation with the authoritative project specifications in `.spec/`, preventing architectural drift and outdated documentation.

---

## What It Updates

- **Requirements**: Fulfills completed user stories and captures new features.
- **Architecture & Tech Stack**: Records new libraries, frameworks, and deployment changes.
- **Diagrams**: Synchronizes Mermaid use-case and sequence diagrams.
- **API Contracts**: Keeps route signatures, payloads, and auth requirements up to date.
- **Data Model**: Reflects database schema migrations, entity relationships, and constraints.
- **Decisions (ADRs)**: Documents foundational design decisions made during development.
