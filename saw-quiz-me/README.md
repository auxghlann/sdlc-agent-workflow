# Knowledge Retention & Recall Quiz Skill (`saw-quiz-me`)

Generates standalone, interactive HTML documentation paired with a self-assessment recall quiz inside `.docs/recall/` to reinforce comprehension of recent architectural and code changes.

---

## Features

- **Interactive Immediate Feedback**: As soon as a user clicks an option, correctness is shown immediately along with detailed technical explanations.
- **Offline & Self-Contained**: Zero external scripts, CDNs, or styles required.
- **Balanced Multiple-Choice Logic**: Distributes correct answers evenly across choice slots (A, B, C, D).
- **Session Technical Synthesis**: Produces concise architectural recaps and code snippet highlights.
- **Strictly No Emojis**: Crisp, professional light-mode aesthetic.
