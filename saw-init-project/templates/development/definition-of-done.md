# Definition of Done (DoD)

## Code Quality Standards

- [ ] All code strictly adheres to project formatting and linter configurations.
- [ ] No unrequested abstractions, speculative features, or dead code.
- [ ] Unbroken adjacent code left untouched.

## Testing & Verification

- [ ] Unit tests written and passing for all modified business logic.
- [ ] Integration tests pass in local/CI environments.
- [ ] Regression checks complete.

## Documentation & Specification Sync

- [ ] Corresponding specifications in `.spec/` updated to match implementation changes.
- [ ] API routes and contracts updated in `.spec/api/` if altered.
- [ ] Architectural decisions documented in `.spec/decisions/` if foundational.
