# SDLC Agent Workflow Help Skill (`saw-help`)

Quick-reference card, navigation guide, and cheatsheet for all SDLC Agent Workflow (`saw-*`) skills, lifecycle phases, commands, and rules.

---

## Features

- **Lifecycle Phase Matrix**: Overview of all 5 development phases from inception (`saw-init-project`) to retention (`saw-quiz-me`).
- **Decision Matrix**: Instant guidance on which skill to invoke based on user intent or workflow state.
- **Visual Lifecycle Flow & Gates**: Detailed flowchart detailing prerequisites and security gates before PR submission.
- **Progressive Disclosure Guide**: Explanation of the 7-level context hierarchy from `.agents/AGENTS.md` to `.spec/` subcomponents.
- **Constitutional Directives**: Consolidated summary of mandatory agent safety constraints (zero secrets, zero emojis, Ponytail decision ladder, Caveman token efficiency).
- **Available Commands**: Quick cheatsheet of all available slash commands and natural language triggers.

---

## Invocation

Invoke this skill anytime to view the reference card:
- Slash command: `/saw-help`
- Natural language: `"saw help"`, `"how do I use the workflow"`, `"what skills are available"`
